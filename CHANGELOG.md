### Changelog

All notable changes to this project will be documented in this file. Dates are displayed in UTC.

#### 0.5.0

- feat: Reviewer Email, Review Due (Hours) and Review Expiry (Days) options — a person reviews the document in DeepRead; the node returns when the job completes with `review.status` pending and the reviewed data arrives at the Webhook URL as `review.completed`
- feat: Webhook URL, Bounding Boxes (`include_markers`) and Per Page options
- fix: polling honours `Retry-After` on `429` and transient `5xx` (the API now answers `503` with `Retry-After` when its database does not respond) instead of failing the item
- docs: plans and per-document limits, Form Fill and PII Redact are Enterprise, API-key monthly spend limit (`402 key_limit_reached`), review webhook events; Preview no longer claims field locations

#### 0.4.1

- docs: two products — Extract $15 and Deep Extract $35 per 1,000 pages; Parse is retired, so every job reports its `product` as `extract` or `deep-extract`. Engine option text and README updated; no behaviour change

#### 0.4.0

- change: Preview is off by default, matching the API. The preview link is public, so it is created only when you turn the option on. Turn Preview on to get page images, the link and field locations as before

#### 0.3.0

- feat: Engine selector (Plan Default / Extract / Deep Extract) sent as the `pipeline` form field
- feat: Options collection on OCR Extract and Structured Extraction: Idempotency Key, Incognito, Preview, Retention (Days)
- docs: Searchable PDF is a Deep Extract add-on on Enterprise plans; every job reports its `product`
- docs: README plans (Free, Standard credits, Enterprise), accepted file types, signed webhooks (`X-DeepRead-Signature`)
